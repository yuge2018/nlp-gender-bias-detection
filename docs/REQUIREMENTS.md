# 课设要求与对应交付

依据本地《课程设计_自然语言处理评测任务综合实践.docx》全文提炼，不改写教师要求。

| 原要求 | 本计划如何满足 | 负责人 |
|---|---|---|
| 从附件选择一个题目，经教师确认 | 用户指定第8题中文文本性别偏见检测 | 全组 |
| 原则上每组5人 | 用户要求6人；需向教师确认编组 | 全组 |
| 至少1种基线与1种改进 | 字符TF-IDF/LR vs 中文预训练编码器 | P2/P3 |
| 相同划分与主要指标公平比较 | 冻结manifest＋Macro-F1＋统一评测器 | P1/P4 |
| 数据检查与必要预处理 | 官方源校验、类别统计、重复与泄漏审计 | P1 |
| 记录预测、指标、日志和主要参数 | 每个run标准目录和元信息 | P2/P3/P4 |
| 主要指标对比和分析、消融、案例分析 | 方法消融＋不同性别对象challenge＋错误分类 | P2/P3/P4/P5 |
| 程序正常运行，可复现主要结果 | 单模块CLI、统一契约、离线模型和复现脚本 | P1–P6 |
| 汇报、程序演示、答辩，人人能说明本人工作 | 每人报告片段、贡献表、答辩题与演示安排 | P1–P6 |

附件中此项是二分类；不自动扩展为偏见类型多标签分类或自动改写。偏见子类型只可用于分析，不能把第9/10题当本题必做内容。
