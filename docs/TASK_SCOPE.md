# 性别偏见检测的任务边界

目标是判断句子是否表达基于性别的刻板印象、角色限制、歧视或贬损。**对象并不限于女性。** 对男性的性格/职业/情绪规范也可能是偏见；涉及其他性别身份时适用同一上下文原则，但数据覆盖必须另行核查。

| 演示例句 | 示例标签 | 依据 |
|---|---|---|
| 男人不该哭，哭就是没出息。 | 1 | 对男性施加情绪角色限制 |
| 女人天生不适合当工程师。 | 1 | 对女性的职业能力作群体判断 |
| 家务必须由女人做，男人只负责赚钱。 | 1 | 同时限制男性与女性的家庭角色 |
| 不符合传统性别表达的人不该被录用。 | 1 | 按性别表达排斥就业 |
| 他今天很难过，所以哭了。 | 0 | 描述个体情绪，没有群体规范 |
| 她是一名工程师。 | 0 | 中性职业事实描述 |
| “男人不能哭”是一种应当反对的刻板印象。 | 0 | 引用并反驳偏见，需要读完整语境 |
| 这个人没有完成任务。 | 0 | 对个体行为评价，本身没有性别归因 |

这些是项目自行编写的接口与讨论示例，不是官方金标，也不是实验成绩。模糊语境允许“待复核”，正式二分类金标仍以冻结数据来源为准。

CORGI-PM 作者的标注包含职业/活动选择、描述/推断、态度/规范/信念三个偏见子类，见[原论文标注规范](https://arxiv.org/html/2301.00395v1#S2.SS2)。本题合并为“有/无偏见”，不输出子类标签。

## 标注与分析规则

1. 区分“被指向对象”和“说话者/作者身份”。仅凭“他/她”不能推断作者性别；不作个人性别身份识别。
2. 目标对象用多标签 `male`、`female`、`other_explicit`、`unspecified`。多个对象可并列，无法判断则记 `unspecified`；`other_explicit` 必须有文本证据，不能靠猜测。
3. 同时纳入针对男性、女性的阳性与阴性例句，包含中性描述、引用/反驳、否定、隐含偏见、角色限制与褒义刻板印象。
4. 人工挑战集在查看模型预测前冻结，至少两人独立复核并记录分歧。P5拥有文件，另一名成员只提交标注意见，不并行改同一文件。
5. 性别替换配对只用作补充诊断，逐对人工确认自然性、语义和标签，不能假设任意替换后标签都相同。
6. 主实验沿用官方金标；发现争议另列，不在看过模型输出后改test金标。自建challenge独立报告，不混入官方测试指标。
7. 分组结果须报告样本数、正/负样本数、FPR、FNR和Macro-F1。没有相应分母记 `null`，不能用0代替。小组样本不足就陈述限制，不声称实现所有性别群体的普遍公平。

任务不限于女性，与数据对各对象是否充分覆盖，是两个分别需要回答的问题。
