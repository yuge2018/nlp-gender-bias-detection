## 工作步骤

1. 用替身先做文本输入、模型切换、结果和阈值展示；不依赖模型内部代码。
2. 真实模式按load_predictor调用，模型懒加载；显示score是模型分数，不猜作者性别。
3. 读取P4标准结果画图和对比，mock模式显著标识；含男性/女性/中性/反驳演示例。
4. 每人写自己报告片段，P6统一格式与叙事，负责系统与交付章节。
5. D10换环境/断网演示，检查提交清单与依赖锁文件，安排6人各自讲解。
