# 实验矩阵和冻结规则

主任务只做有/无性别偏见，不做性别身份预测。P2/P3只读取标准文本，P4统一打分，P5补充诊断。主指标为项目约定的Macro-F1；同时保存正类P/R/F1、负类F1、Accuracy和混淆矩阵。

| ID | 模型/比较 | 控制变量 | 目的 | 负责人 | 优先级 |
|---|---|---|---|---|---|
| B0 | 多数类恒预测，仅作参照 | 同split | 揭示不平衡下Accuracy的局限 | P2 | 必做 |
| B1 | 字符1–3gram TF-IDF＋LR，无类别加权 | 固定数据、seed、训练预算 | 可复现CPU基线 | P2 | 必做 |
| B2 | B1＋balanced class_weight | 仅改权重 | 不平衡处理消融 | P2 | 必做 |
| B3 | 字符1gram vs 1–3gram | 固定权重等配置 | 特征消融 | P2 | 必做 |
| I1 | 中文RoBERTa微调，无类别加权 | 固定split、长度、预算 | 预训练语义表示改进 | P3 | 必做 |
| I2 | I1＋train统计的类别加权 | 仅改loss权重 | 正类召回与误报权衡 | P3 | 必做 |
| I3 | 长度128 vs 256 | 固定其余配置 | 截断敏感性 | P3 | 可选 |
| T1 | 阈值0.5 vs dev最优阈值 | 同checkpoint | 校准决策阈值的影响 | P2/P3/P4 | 必做 |
| S1 | 最终baseline/improved种子42/43/44 | 同数据版本 | 报告均值与波动 | P2/P3/P4 | 资源允许；单次须披露 |
| L1 | 官方划分 vs 清理train同文版 | dev/test不变，匹配不用标签 | 已知重复的敏感性 | P1/P2/P3/P4 | 必做补充，单列 |
| G1 | 男性/女性/多目标/不明确分组 | 相同冻结challenge | 检查范围偏差与FPR/FNR | P5 | 必做 |
| G2 | 中性、引用反驳、否定、隐含/褒义刻板印象 | 不在challenge上调参 | 解释错误与边界 | P5 | 必做 |
| G3 | 人工核验的性别替换对 | 不用作训练增强 | 诊断替换敏感性 | P5 | 可选 |

正式主表至少包括最终B和I的同版本结果；所有消融保留配置差异及原预测，不只抄一个分数。B0不作为“完成改进”的替代品。

## 预算与模型选择

P2在dev上比较 `C∈{0.5,1,2}` 与预定特征/权重选项；P3默认学习率2e-5、epochs3、batch8、max_length128，最多比较学习率1e-5/2e-5、权重开关，预算在首次查看test结果前记录。优先做有解释力的消融，避免无限搜索。

P2/P3以dev Macro-F1选checkpoint/配置；阈值在同一dev网格上选择，并列规则为最接近0.5，再取较小阈值。`test`仅在选定配置、阈值、种子列表后统一评估；不因测试或challenge结果回头改模型再冒充一次盲评。

GPU资源不明。默认只有P3需要GPU；P2/P4/P5/P6均可CPU开发。P3在D2前确认硬件，不可用则采用冻结中文编码器＋LR，或字符/词TF-IDF融合＋类别加权LR作为轻量改进；更新本表与配置，明示其与基线的差别。不要同时跑多个竞争显存的训练。

论文/作者脚本使用的模型、损失和指标输出与本项目可能不同，主表不能直接引用其成绩当作本次实测。当前尚无真实实验结果。
